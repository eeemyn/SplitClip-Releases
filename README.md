# SplitClip
Videoeditor für TikToks, Instagram Reels und YouTube Shorts (Windows 10/11).

**[⬇ Neueste Version herunterladen](https://github.com/eeemyn/SplitClip-Releases/releases/latest)** – unter „Assets“ die Datei `SplitClip-Setup-….exe` wählen.

Windows-Warnung beim Start: „Weitere Informationen“ → „Trotzdem ausführen“. Updates kommen danach automatisch.
