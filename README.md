# SplitClip-Releases
Hey! Ich hab einen eigenen Videoeditor gebaut: SplitClip – für TikToks, Instagram Reels und YouTube Shorts 🎬

So installierst du ihn:
1. Öffne https://github.com/eeemyn/SplitClip-Releases/releases/latest
2. Unten bei „Assets“ auf SplitClip-Setup-….exe klicken (die „Source code“-Dateien brauchst du nicht)
3. Setup starten. Windows zeigt eine Warnung, weil das Programm nicht signiert ist → „Weitere Informationen“ → „Trotzdem ausführen“
4. „Vollständig“ auswählen, dann werden auch automatische Untertitel und Sprachausgabe eingerichtet. Das lädt je nach PC ein paar GB, also kurz Geduld

SplitClip erkennt deinen PC und stellt sich selbst optimal ein. Neue Versionen werden dir beim Start automatisch angeboten.

Funktioniert nur unter Windows 10/11 (64 Bit).
